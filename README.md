# Spam Detection

A simple machine learning project that detects whether a text message is **Spam** or **Not Spam**.

I built this project to practice NLP, machine learning, and deploying a model using Streamlit.

## What I Used

- Python
- Pandas
- NLTK
- Scikit-learn
- Streamlit
- TF-IDF
- Logistic Regression

## How It Works

The message goes through a few steps:

```text
Input Message
     ↓
Text Preprocessing
     ↓
TF-IDF
     ↓
Logistic Regression
     ↓
Spam / Not Spam 
```
